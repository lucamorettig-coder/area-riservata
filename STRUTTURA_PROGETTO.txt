🔗 FLUSSO APPLICAZIONE
======================

1️⃣  REGISTRAZIONE
   Home → Registrazione → [Airtable] → Login (con messaggio successo)

2️⃣  LOGIN
   Home → Login → [Airtable verifica email] → Dashboard

3️⃣  AREA PERSONALE
   Dashboard → Modifica Profilo → [Airtable update] → Dashboard

4️⃣  LOGOUT
   Dashboard → Logout → [Distruggi sessione] → Login

🔒 SICUREZZA
============

✅ Autenticazione cookie-based (sessione 7 giorni)
✅ Pagine protette: dashboard, modifica-profilo
✅ Isolamento dati: ogni genitore vede solo i suoi dati
✅ Validazioni server-side + client-side
✅ Email univoca
✅ Privacy GDPR obbligatoria
